# CZ Designer — Portafolio

Soy CZ, diseñador gráfico. Este es mi portafolio: un espacio para compartir quién soy, cómo pienso y el trabajo que convierto en imágenes, identidades y experiencias visuales.

Aquí puedes conocerme, explorar mis proyectos y ponerte en contacto conmigo para crear algo juntos.

## Sobre el sitio

El portafolio es una sola página con secciones independientes. Cada sección tiene su propio HTML, CSS y JavaScript dentro de `components/`; el header y la navegación general están en `index.html`.

## Ver el portafolio

Como las secciones se cargan dinámicamente, abre el proyecto con Live Server en VS Code o ejecuta `python3 -m http.server 8000` desde la carpeta del proyecto y visita `http://localhost:8000`.
